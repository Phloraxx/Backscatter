# Backscatter: source attribution and release readiness

Updated November 14, 2026. This is a rights and credit checklist, not a license grant.

## Data and imagery used

- NASA–ISRO NISAR: validated L-band Level-2 GCOV HHHH and, for Kuttanad, HVHV products obtained via Alaska Satellite Facility / Earthdata. Individual granule IDs and processing identifiers are recorded in each study's scene_manifest.json.
- NASA OPERA: DSWx-HLS and DSWx-S1 surface-water classification products from PO.DAAC. OPERA is an independent satellite-derived reference, NOT field-confirmed flooding; HLS and S1 class definitions and acquisition dates differ.
- India Meteorological Department: October 28, 2026 Cyclone Arnab landfall report, https://mausam.imd.gov.in/Forecast/mcmarq/mcmarq_data/Press%20Release%20Dtd%2028.10.2026.pdf.
- International Charter for Space and Major Disasters: Cyclone Arnab/Flood in India, activation 1056, used ONLY for context. No Charter flood maps have been republished.
- OpenStreetMap contributors: the basemap displayed inside MapLibre. The attribution is included with the map. The community tile server has a usage policy and is not suitable for arbitrary large-scale traffic.
- Backscatter's original team-provided logo, original graphic design, and screenshots of the resulting application. Confirm permission to redistribute the brand assets.

## AI disclosure

ChatGPT/OpenAI assisted with research, prototyping, code implementation, testing, debugging, evidence interpretation, reports and slide preparation. Scientific metrics were calculated by deterministic source code against real downloaded satellite data, not generated by an LLM. No trained flood detector or field-validated flooding map is claimed. Ask teammates whether other AI or software services must also be disclosed.

## Material open questions before NASA submission

1. This repository still has **NO chosen open-source LICENSE**. Team members must approve an appropriate license for original code, graphics and documentation; for example, MIT for code with separate branding provisions. Do not assume that making a website public makes its code openly licensed.
2. The GitHub repository is currently **PUBLIC** (verified via GitHub API on November 14, 2026). Judges can open both source code and the live website. However, public visibility is not the same as an open-source license. The six-person team should confirm the original code/branding release terms before judging. The audit did NOT change visibility.
3. NASA restricts recognizable names, faces and voices of anyone under 18. The PDF lists all six NASA team members by name. Confirm that this is permitted for **each** member; remove prohibited identification before submission.
4. Research and team formation before November 14 are allowed; developing this specific challenge implementation before 9 AM on November 14 may not be. Record the accurate dates and obtain a Local Lead/GO Team ruling when unclear. Do not rewrite history.
5. All six members should confirm completion of the separate Thrissur participation form (virtual participation included). One team member's registration confirmation does not establish the others' status.

## Security and provenance

The scientific methods, JSON metric reports, source SHA-256 checksums and derived small visualizations are in Git. Authenticated source GeoTIFFs/HDF5 files and NASA Earthdata access tokens stay outside Git and the public website. Any access token previously shared in conversation or plaintext should be revoked/rotated by its owner.

For NASA reference fields cite the exact NISAR and OPERA missions, product identifiers, NASA ASF/Earthdata, PO.DAAC, the official NISAR resource page, and external event context separately.
