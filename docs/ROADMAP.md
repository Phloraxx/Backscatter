# Roadmap

## Stage 0 — data proof
- find compatible scene pair;
- extract AOI;
- visualize calibrated backscatter.

## Stage 1 — change baseline
- dB conversion;
- difference/ratio;
- simple adaptive water-change baseline.

## Stage 2 — validation
- acquire independent reference;
- calculate precision/recall/F1/IoU;
- document failure cases.

## Stage 3 — product demo
- optimized rasters;
- case catalog API;
- map UI;
- evidence inspector.

## Stage 4 — scientific improvement
- polarization features;
- terrain/context features;
- optional coherence.

## Stage 5 — transfer test
- run unchanged or minimally retuned pipeline on a second event.

## Stage 6 — stretch
- flooded vegetation;
- L/S fusion;
- coastal change;
- selected InSAR/deformation module.

A stage cannot be called complete without an inspectable artifact or metric.
