# Suggested Team Workstreams

## Science / data
Own:
- NISAR discovery;
- compatible scene selection;
- processing;
- validation.

## Backend / geospatial
Own:
- artifact generation;
- metadata;
- FastAPI;
- tile/COG serving;
- caching.

## Frontend / visualization
Own:
- MapLibre;
- timeline;
- swipe/compare;
- evidence panel;
- responsive demo.

## Story / research
Own:
- source verification;
- problem narrative;
- scientific caveats;
- pitch;
- submission copy.

## Integration rule

Every workstream must use the same case IDs and provenance schema.
