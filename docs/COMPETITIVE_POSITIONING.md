# Competitive Positioning

## Weak implementation

"NISAR imagery browser with AI chatbot."

Problems:
- low analytical novelty;
- weak scientific transformation;
- AI is doing presentation rather than measurement;
- easy for many teams to reproduce.

## Strong implementation

"Evidence-driven surface-change intelligence."

Characteristics:
- compatible observation pairing;
- measured backscatter change;
- physically motivated classification;
- confidence;
- independent validation;
- fast interactive visualization;
- transparent provenance.

## Core differentiator

**Change → Evidence → Explanation**

The user should be able to inspect why a region was marked as changed.

## Pitch contrast

Other tools often answer:
"What does this satellite image look like?"

Backscatter should answer:
"What changed between these radar observations, how much changed, and what evidence supports that interpretation?"
